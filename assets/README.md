# Profile artwork

All assets are stored in this repository. The profile has no third-party badge or image-generation service dependencies.

## Signal station banners

The `signal-station-*.svg` files are original vector artwork generated by `scripts/build-art.mjs`. The desktop composition is 1280 × 420; mobile is 720 × 708. The README selects the layout and colour scheme with `<picture>`. SVGs contain accessible descriptions and no scripts, external fonts, or remote images.

GitHub rewrites colour-scheme source conditions and discards additional width conditions. The mobile source therefore uses only a width query, and `signal-station-mobile.svg` inherits the embedding page's colour scheme through its own CSS. The explicit mobile light/dark variants are retained as reference artwork.

Regenerate from the repository root:

```sh
node scripts/build-art.mjs
```

## Refreshing the RFTUI animation

Requires the reviewed RFTUI checkout and its Python environment, `rsvg-convert`, and `ffmpeg`. Store intermediate frames outside this repository. The capture script checks the source revision and refuses uncommitted application code; review any new revision before updating that check.

```sh
/path/to/rftui/.venv/bin/python scripts/capture-rftui.py \
  --source /path/to/rftui --frames /path/to/work/rftui-frames

ffmpeg -framerate 6 -i /path/to/work/rftui-frames/%03d.png \
  -filter_complex '[0:v]select=not(mod(n\,2)),setpts=N/(3*TB),scale=900:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=96:stats_mode=diff[p];[b][p]paletteuse=dither=none' \
  -r 3 -loop 0 assets/rftui-demo.gif

cp /path/to/work/rftui-frames/000.png assets/rftui.png
```

Keep essential descriptions as selectable README text and retain alt text for every image. Check the profile on desktop and mobile in both themes after asset updates.
